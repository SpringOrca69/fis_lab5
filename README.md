# HeartPay

A mobile web proof of concept that helps older heartland merchants in Singapore accept CDC vouchers by scanning the customer's QR code.

## Translations

The Chinese (ZH), Malay (MS) and Tamil (TA) text, including the video captions in `public/captions`, is AI-drafted. It needs review by native speakers before any real use. Run `npm run check:i18n` to check that every language has every key.
